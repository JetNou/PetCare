# 🐾 PetCare – Pet Health Monitoring Platform

> **PetCare** — веб-платформа для учета домашних животных и контроля их здоровья.
> Позволяет владельцам хранить медицинскую историю питомцев, планировать ветеринарные процедуры и получать автоматические напоминания.

**Версия:** 1.0
**Статус:** MVP / Production Ready
**Тип проекта:** Учебный проект

---

# 🎯 Идея проекта

Современные владельцы домашних животных часто сталкиваются с проблемой хранения и отслеживания медицинской информации о питомцах.

Приложение **PetCare** решает эту проблему, предоставляя **единое цифровое пространство**, где можно:

🐕 хранить профили питомцев
💊 вести медицинскую историю
📅 отслеживать будущие ветеринарные процедуры
📧 получать email-напоминания
📄 экспортировать медицинские отчёты

---

# 🚀 Быстрый запуск

## ▶️ Запуск приложения

Для запуска всей системы используется готовый скрипт.

```bash
./start.bat
```

Скрипт автоматически:

* активирует виртуальное окружение
* запускает backend
* запускает frontend
* запускает необходимые фоновые процессы
* подготавливает окружение для работы приложения

После запуска приложение будет доступно по адресу:

```
http://localhost:8000/api/v1
```

API документация:

```
http://localhost:8000/api/docs
http://localhost:8000/api/redoc
```

# ⚙️ Тестирование фоновых задач

В проекте реализована система **фоновых уведомлений (email-напоминаний)**.
Для проверки её работы предусмотрены специальные тестовые скрипты.

## 1️⃣ Активация виртуального окружения

Перед запуском тестов необходимо активировать `venv` и перейти в директорию backend.

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```


```bash
cd backend
```

---

## 2️⃣ Тест работоспособности системы уведомлений

Проверяет базовую работу системы уведомлений.

```bash
python test_notifications.py
```

Этот тест:

* проверяет запуск scheduler
* проверяет обработку событий
* проверяет отправку уведомлений

---

## 3️⃣ Тест с реальными данными

Запускает отправку уведомления на основе **реальных записей из базы данных**.

```bash
python test_immediate_notification.py
```

Тест:

* ищет медицинские события в базе
* проверяет условие отправки уведомления
* отправляет email уведомление пользователю

---

💡 Используется для проверки:

* работы **APScheduler**
* корректности **email-рассылки**
* логики **планирования событий**

Связи:

```
User 1 ---- * Pets
Pets 1 ---- 1 MedicalHistory
MedicalHistory 1 ---- * MedicalAction
```
